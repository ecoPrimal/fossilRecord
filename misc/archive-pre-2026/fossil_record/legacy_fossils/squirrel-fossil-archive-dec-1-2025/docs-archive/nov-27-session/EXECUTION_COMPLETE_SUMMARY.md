## 🎓 PROVEN MIGRATION PATTERNS

### Pattern Library (Validated & Working)

#### 1. Simple Port Configuration
```rust
use universal_constants::network;
let port = network::get_port_from_env("SERVICE_PORT", network::DEFAULT_HTTP_PORT);
let url = network::http_url(network::DEFAULT_LOCALHOST, port, "/api");
```

#### 2. Multi-Endpoint from Single Port
```rust
use universal_constants::network;
let base_port = network::get_port_from_env("BASE_PORT", 5000);
let endpoints = json!({
    "api": network::http_url(network::DEFAULT_LOCALHOST, base_port, "/api"),
    "health": network::http_url(network::DEFAULT_LOCALHOST, base_port, "/health"),
});
```

#### 3. Environment-Aware Host Binding
```rust
use universal_constants::network;
let host = if is_production() {
    network::DEFAULT_BIND_ADDRESS  // "0.0.0.0"
} else {
    network::LOCALHOST_IPV4       // "127.0.0.1"
};
```

#### 4. JSON Macro Compatibility
```rust
// Pre-compute before json! macro
let endpoint = {
    use universal_constants::network;
    let port = network::get_port_from_env("PORT", 8080);
    format!("http://{}:{}/path", network::DEFAULT_LOCALHOST, port)
};
let config = json!({ "endpoint": endpoint });
```

#### 5. Console Output Consistency
```rust
println!("API: http://{}:{}/api", 
    universal_constants::network::DEFAULT_LOCALHOST, 
    port);
```
