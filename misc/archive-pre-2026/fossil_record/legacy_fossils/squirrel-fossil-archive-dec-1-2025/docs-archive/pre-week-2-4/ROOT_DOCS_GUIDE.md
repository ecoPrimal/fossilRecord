## 📝 Documentation Standards

### File Naming
- Use SCREAMING_SNAKE_CASE for process docs
- Use Title Case for guides (with underscores)
- Date format: NOV_26_2025 or nov-26-2025 (lowercase in paths)

### Content Standards
- **Reality over hype**: Honest assessments
- **Metrics-driven**: Concrete numbers
- **Actionable**: Clear next steps
- **Maintained**: Keep current

### Organization Principles
1. Root = High-level, frequently accessed
2. docs/ = Detailed reference
3. docs/sessions/ = Dated reports
4. No duplicates across locations
