## 📋 Maintenance Guidelines

### When to Archive

Archive documents when:
- Superseded by newer versions
- No longer relevant
- Historical reference only
- Confusing if kept in root

### When to Keep in Root

Keep in root when:
- Currently active/relevant
- Frequently referenced
- Core project documentation
- Clear entry points

### Naming Convention

- **⭐⭐⭐** - Primary entry point
- **⭐** - Important audit document
- **📍** - Completion marker
- **🎉** - Achievement marker
- **Date suffix** - _NOV_4_2025 for versioning
