### When to Archive Docs
Archive a document when:
- It's been superseded by a newer version
- It's a session report that's now complete
- It's historical but worth preserving
- It's cluttering the root directory

**Archive Location**: `docs/archive/session_reports_[date]/`

### When to Delete Docs
Delete a document when:
- It's genuinely wrong/misleading
- It's a true draft with no value
- It's causing confusion and has no historical value

**Note**: We prefer archiving over deleting!
