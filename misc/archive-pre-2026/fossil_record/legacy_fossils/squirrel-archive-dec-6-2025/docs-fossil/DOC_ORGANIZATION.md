## 🧹 Organization Principles

### Root Level = Essential Only
- Frequently accessed
- Primary entry points
- Always current
- Maximum 10 files

### docs/ = Organized by Purpose
- **sessions/** - Detailed session work
- **summaries/** - High-level overviews
- **analysis/** - Deep technical analysis
- **planning/** - Strategic plans
- **migration/** - How-to guides
- **architecture/** - Core decisions

### File Naming Convention
- `SESSION##_*` - Session reports
- `NOV_8_*` - Date-specific summaries
- `*_COMPLETE*` - Finished work
- `*_QUICK_SUMMARY*` - TL;DR versions
- `*_ROADMAP*` - Future planning
- `*_GUIDE*` - How-to instructions
