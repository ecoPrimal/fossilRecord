## 🎯 Maintenance Guidelines

### Adding New Documentation
1. **Core docs**: Add to root with clear purpose
2. **Session reports**: Create `docs/sessions/YYYY-MM-DD/` directory
3. **Detailed docs**: Add to appropriate `docs/` subdirectory
4. **Update indexes**: ROOT_DOCS_INDEX.md and session README.md

### Updating Existing Documentation
1. Update the file in place
2. Update "Last Updated" date
3. Update related indexes if needed
4. Keep old versions in session archives

### Archiving Old Sessions
1. Move to `docs/sessions/YYYY-MM-DD/`
2. Create or update session README.md
3. Update ROOT_DOCS_INDEX.md
4. Keep critical files at root (handoff, templates)

### Cleaning Root
1. Keep only essential files
2. Move session work to sessions directory
3. Remove duplicates
4. Update navigation files
